## 安装 / 卸载 / 升级验收

- 安装：用户级安装（无需管理员权限），`%LOCALAPPDATA%\Programs\FundLens`。
- 升级：原位升级，`%APPDATA%\FundLens` 用户数据（加密数据库）不受影响。
- 卸载：默认保留用户数据，删除需显式勾选。
- 干净 VM 验收：沿用 `tests/release/clean_vm_acceptance.ps1` 清单，本机无干净 VM，未执行。
