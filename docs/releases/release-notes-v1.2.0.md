# FundLens v1.2.0

本地资产快照分析工具（Windows 桌面）。本版本聚焦界面交互与工程化：暗色模式、视图状态记忆、图表 hover 与微动画，同时完成存储层与发布流水线加固，共 6 个提交。

## 界面与交互

- **暗色模式**：设置 → 外观中选择「跟随系统 / 浅色 / 深色」，暖墨色系整体压暗，对比度满足 WCAG AA
- **表格行密度**：舒适（56px）/ 紧凑（44px）切换，全部持仓表格即时生效
- **趋势图悬停**：悬停净值趋势图显示十字线与该日期的总资产、覆盖成本
- **数字滚动动画**：行情刷新或导入后，KPI 金额与占比平滑过渡到新值（系统"减少动画"开启时自动关闭）
- **骨架屏加载**：总览页加载中显示页面轮廓而非转圈，避免布局跳动
- **页面切换淡入**：150ms 淡入过渡，性能预算内（423ms < 500ms）
- **Hover 反馈与常驻滚动条**：表格行、导航项、列表项统一的暖墨 hover 底色；滚动条常驻可见、悬停加粗

## 视图状态记忆

- 窗口尺寸与位置跨会话恢复
- 侧栏折叠状态、最后访问页面、持仓排序方式自动记忆

## 安装与更新

下载下方 **FundLens-Setup.exe**（约 263 MB，含内置 Python 数据引擎与本地 OCR 模型），按用户级安装即可，无需管理员权限。已安装 v1.1.1+ 的用户可在「设置与备份 → 应用信息」中检查更新。卸载默认保留 `%APPDATA%\FundLens` 用户数据。

> 数据全部本地处理：SQLCipher 加密数据库、Argon2id + AES-256-GCM 备份、截图 OCR 本地识别，不上传云端。
