# FundLens v1.3.0

本地资产快照分析工具（Windows 桌面）。本版本聚焦截图 OCR 导入的识别率与审核体验：同花顺滚动截屏全链路打通、识别错误自动兜底，导入审核界面两处关键修复。

## 截图识别（同花顺）

- **滚动截屏续页识别**：后续页没有列表表头时自动沿用上一页列位置，行内附提示请人工核对
- **跨页自动去重**：相邻页重叠导致同一持仓识别两次时，自动保留首次出现的行；名称区域识别受损但数值一致的残缺副本自动移除（info 级提示可见，无需操作）
- **损坏行打捞**：名称没认出来但 盈亏/持仓/成本 数字齐全的行不再静默丢弃，生成待补填行由人工确认
- **贴边数字补救**：检测框错位导致的高置信末位丢失（如成本价 1.879 → 1.87）通过加宽框二次识别自动纠正，仅在严格「补回被裁字符」语义下采纳
- **表头容错**：排序箭头（市值⇅）、全角斜杠（持仓／可用）不再导致整页识别失败；「最新」行情行整行剔除容差随字号自适应

## 资产分类

- 同花顺持仓全部归为**场内基金（ETF）/ 权益类**
- 支付宝按产品名称下方标签分类：**稳健理财 → 固收类**、**进阶理财 → 权益类**；标签未识别时保持未分类，由审核界面提示人工确认

## 导入审核界面修复

- 修复多页截图时后续页的识别问题错误归属到前几页持仓卡片上
- 修复删除一行后下一行卡片沿用被删行输入内容（名称显示串位）的问题

## 安装与更新

下载下方 **FundLens-Setup.exe**（约 275 MB，含内置 Python 数据引擎与本地 OCR 模型），按用户级安装即可，无需管理员权限。已安装 v1.1.1+ 的用户可在「设置与备份 → 应用信息」中检查更新。卸载默认保留 `%APPDATA%\FundLens` 用户数据。

> 数据全部本地处理：SQLCipher 加密数据库、Argon2id + AES-256-GCM 备份、截图 OCR 本地识别，不上传云端。
