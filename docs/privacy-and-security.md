# FundLens 隐私与安全说明

本文说明 FundLens V1 如何处理和保护你的数据。所有设计遵循同一原则：**数据不出本机**。

## 本地处理

- 全部持仓、截图、快照和备份都在本机处理，不上传任何云端服务；
- 截图 OCR 由应用内置的本地数据引擎完成，不调用在线识别接口；
- 网络访问只有两类：向免费公开行情数据源查询价格或净值，以及你在设置页主动点击“检查更新”时向更新清单地址发起的一次 HTTPS 请求；两类请求都不包含你的持仓金额、快照或个人信息。

## 数据库加密

- 本地数据库使用 sqlite3mc（SQLCipher 兼容）透明加密；
- 数据库密钥由 Windows 凭据管理器（Windows Credential Manager）保护，不以明文落盘，也不写入日志或备份文件的明文区域。

## 备份加密

- 备份文件（`.fundlens-backup`）使用 **Argon2id** 从你的备份密码派生密钥（32 字节密钥、16 字节随机盐、3 次迭代、65536 KiB 内存、1 lane），再使用 **AES-256-GCM**（12 字节随机 nonce、128 位认证标签）做认证加密；
- 每份备份都使用独立生成的随机盐和 nonce；
- 数据库密钥只存在于密文载荷内，使备份可以恢复到另一台 Windows 机器；明文头部只记录格式版本、算法参数和校验值；
- 备份密码永不保存、永不记录，也不会传给数据引擎。忘记密码意味着该备份无法恢复。

## 恢复保护

- 恢复时先在临时目录解密，验证载荷 SHA-256 校验值和数据库结构版本，全部通过后才原子替换当前数据库；
- 替换前自动保留当前数据库的可恢复副本；
- 密码错误、文件被篡改或版本不支持的备份会被统一拒绝，恢复失败不会改变当前数据。

## 临时文件

- 截图导入过程中产生的临时副本和中间 OCR 图像，在确认导入或显式丢弃后会被清理；
- 应用绝不会删除你的原始截图文件。

## 应用更新

- 检查更新只在你主动点击时发生，应用不会自动联网检查；
- 下载的安装包必须通过清单中公布的 SHA-256 校验才会被启动，校验失败的文件会被直接删除；
- 更新为原位升级，`%APPDATA%` 下的用户数据（包括加密数据库）不受影响。

## 日志脱敏

应用日志不记录：

- 完整持仓金额；
- 原始 OCR 文本或截图内容；
- 数据库密钥、备份密码或任何凭据。

## 进程边界

内置数据引擎以独立子进程运行，只能访问应用数据目录和你明确选择的文件。卸载应用时默认保留 `%APPDATA%\FundLens` 下的用户数据；只有你在卸载确认对话框中明确勾选删除选项，数据才会被移除。
