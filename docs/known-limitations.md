# FundLens V1 已知限制

V1 聚焦“本地资产快照分析”这一件事。以下能力是**有意不提供**的，不是缺陷。

## 不支持的资产与数据

- **无直接持有的债券**：不单独支持国债、公司债、地方债和可转债；债券类暴露仅通过债券基金纳入。
- **无交易流水**：不记录申购、赎回、买入、卖出流水，不做精确资金流跟踪。
- **无实时行情**：不提供实时分时行情和分时图。场内资产使用最近交易日收盘价，场外基金使用最新已公布净值，每条行情标注来源和日期。

## 平台与账号

- **无云同步、无账号体系**：没有云端账户、登录、多用户或跨设备同步；所有数据只保存在本机。
- **无 Android 客户端**：V1 只交付 Windows 桌面应用，不提供 Android 页面、构建或 APK。
- **不自动登录平台**：不自动登录支付宝、同花顺或券商账户；持仓通过文件和截图导入。

## 分析与决策边界

- **不提供投资建议**：不包含买入、卖出、加仓、减仓、调仓或再平衡建议，不提供默认“理想配置比例”；结构观察只展示实际比例，或与用户自行设置的阈值比较。
- **无量化风险指标**：不计算 VaR、最大回撤、波动率、夏普率等指标。
- **快照差额不等于投资收益**：两个快照之间的差额只称为“资产金额变化”，它混入了行情波动和资金进出，不能被解释为投资收益。
- **无自动交易**：FundLens 不与任何交易接口连接。

## 数据源风险

行情来自免费公开数据源，接口可能变化或失效。行情失败时应用保留上次有效值并显示过期状态；单一数据源失效不会破坏数据库或主应用。
