# Triage 标签

技能以五个规范 triage 角色来表述。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 技能角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

当技能提到某个角色（例如“打上 AFK-ready 标签”），使用表中对应的标签字符串。

如需改用本仓库现有的其它命名，编辑右列即可。
