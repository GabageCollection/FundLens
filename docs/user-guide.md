# FundLens 用户指南

FundLens 是一款面向个人投资者的本地资产快照分析工具。它把来自支付宝、同花顺和手动录入的持仓统一汇总，在 Windows 桌面端展示总资产、资产结构、当前浮动盈亏和历史快照变化。

FundLens 的基本原则是：先统计，再分析；只描述资产事实，不代替用户作出投资决策。应用内不包含任何买入、卖出或调仓建议。

## 六个页面

左侧固定导航包含六个页面：

| 页面 | 用途 |
|---|---|
| 资产总览 | 总资产、持有成本、浮动盈亏、资产光谱、结构观察、主要持仓和行情状态 |
| 资产分析 | 按资产类别、产品形态和来源平台分析金额、占比、浮动盈亏及集中度 |
| 全部持仓 | 搜索、筛选、排序、新增、编辑、删除持仓，手动刷新行情 |
| 历史快照 | 保存快照，对比两个日期的总资产、持仓金额和资产结构变化 |
| 导入与识别 | Excel/CSV 导入、截图 OCR、字段预览、数据问题处理和确认写入 |
| 设置与备份 | 分类规则、结构提示阈值、行情设置、加密备份、恢复和隐私设置 |

界面颜色遵循国内习惯：红色表示盈利，绿色表示亏损；颜色之外同时提供正负号和文字说明。

## 支持的资产类型

V1 支持以下持仓：

- 现金与现金管理：现金、余额宝、货币基金等；
- 银行存款：活期、定期和大额存单等；
- 场内股票；
- 场内基金：ETF、LOF 和公募 REITs 等；
- 场外基金：ETF 联接基金、指数基金、主动基金、混合基金、债券基金、FOF 和 QDII 等；
- 黄金与贵金属：黄金 ETF、黄金基金、积存金、纸黄金和手工估值的实物黄金。

每笔持仓有两个分类维度：**产品形态**（现金管理、银行存款、股票、ETF、LOF、REIT、场外基金、积存金、实物黄金）和**资产类别**（现金、存款、权益、固定收益、混合、黄金、其他）。例如黄金 ETF 的产品形态是 ETF，资产类别是黄金。

V1 不单独支持直接持有的国债、公司债、地方债和可转债；债券类暴露仅通过债券基金纳入。

## 导入持仓

### 手动添加

在“全部持仓”页点击“添加持仓”，填写产品名称、金额等字段后保存。手动录入的持仓不会被任何平台导入覆盖。

### CSV / Excel 导入

在“导入与识别”页选择 CSV 或 Excel 文件。CSV 模板见 `docs/import-template/fundlens-import-template.csv`。导入前会显示字段预览，确认后以单个事务写入。

### 截图 OCR 导入

在“导入与识别”页选择支付宝或同花顺持仓截图（可一次选择多张连续长截图）。识别完全在本地完成。每个字段带有置信度，预览时可以并排核对截图局部与识别结果；关键金额、产品名称或正负号不确定时禁止直接确认，需要人工修正后再写入。

### 部分持仓与完整持仓

每次截图导入必须选择一种模式：

- **部分持仓**（默认）：只新增或更新识别到的产品，不删除该平台的其他记录；
- **完整持仓**：允许用本次识别结果替换该平台的全部现有持仓。

支付宝导入只更新支付宝来源，同花顺导入只更新同花顺来源。相同平台、相同产品代码视为同一持仓；模糊匹配的候选不会自动合并，必须由用户确认。

## 行情与日期

- 行情来自免费公开数据源（BaoStock、AKShare），每天启动时最多自动更新一次，也可以在“全部持仓”或“设置与备份”页手动刷新；
- 场内资产使用**最近交易日收盘价**，场外基金使用**最新已公布净值**，不是实时行情；
- 每条行情都显示来源和估值日期；
- 行情获取失败时保留上次有效值并显示过期状态，不会用零值替代；
- 支付宝等只有金额、没有份额的来源，保留最近一次确认的当前金额，最新净值仅作参考，不反推资产金额；
- 行情刷新只修改当前持仓，绝不修改历史快照。

## 快照的含义

快照是某一时刻全部持仓的**冻结副本**：保存后所有字段不可修改，后续行情刷新和持仓编辑都不会改变它。

对比两个快照时，差额只标注为“**资产金额变化**”。它描述两个时点之间的金额差异，可能来自行情波动、存入、取出或导入修正，**不等于投资收益**。

## 备份与恢复

- 在“设置与备份”页创建加密备份（`.fundlens-backup` 文件），备份由你设置的密码保护；密码不会被保存或记录，忘记密码将无法恢复该备份；
- 恢复时先在临时区域解密并验证备份完整性和结构版本，通过后才原子替换当前数据库；替换前会自动保留当前数据库的可恢复副本，恢复失败不会破坏现有数据；
- 密码错误、文件损坏或版本不支持的备份会被拒绝，当前数据保持不变。
